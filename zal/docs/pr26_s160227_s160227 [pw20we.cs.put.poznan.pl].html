Opis problemu

Projekt polega na znalezieniu grafów całkowitych wśród zbioru grafów dwudzielnych dla liczby wierzchołków n = 17 oraz liczby krawędzi k = 42. Grafy generowane są za pomocą programu nauty i zapisane do pliku tekstowego. Programy przyjmują jako argumenty nazwę pliku z grafami oraz liczbę linii do przeanalizowania. Głównym celem jest porównanie wersji sekwencyjnej algorytmu z wersjami równoległymi (OpenMP oraz CUDA).

Spis zaimplementowanych algorytmów

Lp. Algorytm (KOD) Kategoria Przeznaczenie
1 AGE1 Generator danych Zamiana kodu Graph6 na macierz sąsiedztwa
2 JAC1 Numeryczny/Algebra Wyliczenie wartości własnych
3 ASEQ1 Algorytm sekwencyjny Analiza widmowa grafów w jednym wątku
4 APAR1 Algorytm równoległy (OpenMP) Przyspieszenie analizy widmowej na procesorach wielordzeniowych przy użyciu OpenMP
5 APAR2 Algorytm równoległy (CUDA) Masowe przyspieszenie analizy widmowej na procesorach graficznych przy użyciu CUDA

Opis algorytmu ASEQ1

Algorytm ASEQ1:
Dane: Plik tekstowy ze zbiorem grafów w formacie Graph6 (lub ze standardowego wejścia) oraz opcjonalny limit liczby grafów do odczytu.
Wynik: Wypisane na standardowe wyjście (konsolę) identyfikatory i kody Graph6 znalezionych grafów całkowitych oraz czas wykonania.
Metoda:
  1. Uruchom zegar pomiarowy
  2. Dopóki nie osiągnięto limitu i są kolejne linie w pliku:
    1. Wczytaj linię tekstu z pliku.
    2. Wywołaj algorytm DEC1, aby utworzyć macierz sąsiedztwa.
    3. Wywołaj algorytm JAC1 dla macierzy, uzyskując tablicę n wartości własnych.
    4. Zweryfikuj, czy każda wartość w tablicy różni się od najbliższej liczby całkowitej o mniej niż EPS.
    5. Jeśli warunek jest spełniony, wypisz wynik.
  3. Zatrzymaj zegar i wyświetl podsumowanie.

Opis algorytmu APAR1

Algorytm APAR1:
Dane: Plik tekstowy ze zbiorem grafów w formacie Graph6 (lub ze standardowego wejścia) oraz opcjonalny limit liczby grafów do odczytu.
Wynik: Wypisane na standardowe wyjście (konsolę) identyfikatory i kody Graph6 znalezionych grafów całkowitych oraz czas wykonania.
Metoda:
  1. Zanotuj czas startu
  2. Powołaj pulę niezależnych wątków roboczych, przydzielając każdemu własną pamięć.
  3. We wspólnej pętli wykonywanej przez każdy wątek z puli:
    1. Zablokuj dostęp innym wątkom, wczytaj linię tekstu z pliku, zaktualizuj globalny licznik i zdejmij blokadę.
    2. Wywołaj algorytm DEC1 w pełni równolegle, aby utworzyć macierz sąsiedztwa.
    3. Wywołaj algorytm JAC1 dla macierzy w pełni równolegle, uzyskując tablicę n wartości własnych.
    4. Zweryfikuj całkowitość wartości własnych.
    5. Jeśli graf jest całkowity, zablokuj dostęp do strumienia wyjścia, wypisz wynik i zdejmij blokadę.
  4. Połącz wątki na końcu pliku, zatrzymaj zegar i wyświetl podsumowanie.

Opis algorytmu APAR1

Algorytm APAR2:
Dane: Plik tekstowy ze zbiorem grafów w formacie Graph6 (lub ze standardowego wejścia) oraz opcjonalny limit liczby grafów do odczytu.
Wynik: Wypisane na standardowe wyjście (konsolę) identyfikatory i kody Graph6 znalezionych grafów całkowitych wraz z czasem odnotowanym dla danej porcji (paczki) danych.
Metoda:
  1. Zaalokuj pamięć na hoście (CPU) oraz urządzeniu (GPU) na paczkę tekstową o wielkości BATCH_SIZE oraz na odpowiadającą jej tablicę wyników (0 lub 1).
  2. Uruchom zegar pomiarowy.
  3. Dopóki nie osiągnięto limitu i są kolejne linie do wczytania:
    1. (CPU) Wczytaj linię tekstu i dopisz ją do bufora paczki w pamięci RAM.
    2. Jeśli paczka została zapełniona lub nastąpił koniec pliku danych:
      1. (CPU → GPU) Skopiuj całą paczkę kodów Graph6 z pamięci hosta do pamięci globalnej GPU.
      2. (GPU) Uruchom kernel CUDA, przypisując jeden wątek karty graficznej do dokładnie jednego grafu z paczki.
      3. (Wątek GPU) Skopiuj swój przydzielony łańcuch znaków do pamięci lokalnej (rejestrowej).
      4. (Wątek GPU) Wywołaj algorytm DEC1 na urządzeniu.
      5. (Wątek GPU) Wywołaj algorytm JAC1 na urządzeniu, wyliczając wartości własne.
      6. (Wątek GPU) Zweryfikuj całkowitość i zapisz wynik (1 - prawda, 0 - fałsz) we fragmencie globalnej tablicy wyników odpowiadającym indeksowi wątku.
      7. (GPU →→ CPU) Po zsynchronizowaniu pracujących bloków, skopiuj tablicę wyników z GPU do pamięci RAM hosta.
      8. (CPU) Posiadając tablicę wyników, wypisz na konsolę grafy, które na odpowiadającym im indeksie posiadają wartość 1 (zostały oznaczone jako całkowite).
      9. (CPU) Wyzeruj wielkość aktualnej paczki i przejdź do zbierania kolejnych danych.
  4. Zatrzymaj zegar, wyświetl podsumowanie i zwolnij zaalokowaną pamięć z karty oraz procesora.

Wersja sekwencyjna

sito_seq.c
#include <stdio.h>
#include <stdlib.h>
#include <math.h>
#include <string.h>
#include <time.h>
 
#define N 17 
#define EPS 1e-6
 
void getEigenvalues(double m[N][N], int n, double evals[N]) {
    for(int it=0; it<500; it++) {
        double max_v = 0;
        int p=0, q=1;
        for(int i=0; i<n; i++) {
            for(int j=i+1; j<n; j++) {
                if(fabs(m[i][j]) > max_v) { 
                    max_v = fabs(m[i][j]); 
                    p=i; q=j; 
                }
            }
        }
        if(max_v < 1e-12) break;
 
        double theta = (m[q][q] - m[p][p]) / (2.0 * m[p][q]);
        double t;
        if (fabs(theta) < 1e10) {
            t = (theta >= 0) ? 1.0/(theta + sqrt(1+theta*theta)) : -1.0/(-theta + sqrt(1+theta*theta));
        } else {
            t = 0.5 / theta;
        }
 
        double c = 1.0 / sqrt(1+t*t);
        double s = t*c;
        double tau = s/(1.0+c);
        double apq = m[p][q];
 
        m[p][p] -= t*apq; 
        m[q][q] += t*apq; 
        m[p][q] = m[q][p] = 0;
 
        for(int i=0; i<n; i++) {
            if(i!=p && i!=q) {
                double aip = m[i][p], aiq = m[i][q];
                m[i][p] = m[p][i] = aip - s*(aiq + aip*tau);
                m[i][q] = m[q][i] = aiq + s*(aip - aiq*tau);
            }
        }
    }
    for(int i=0; i<n; i++) evals[i] = m[i][i];
}
 
int decodeGraph6(const char* g6, double adj[N][N]) {
    if (g6[0] < 63 || g6[0] > 126) return 0;
    int n = g6[0] - 63;
 
    for(int i=0; i<n; i++) 
        for(int j=0; j<n; j++) adj[i][j] = 0.0;
 
    int char_ptr = 1;
    int bit_ptr = 0;
    int current_val = 0;
 
    for (int j = 1; j < n; j++) {
        for (int i = 0; i < j; i++) {
            if (bit_ptr == 0) {
                current_val = g6[char_ptr++] - 63;
                bit_ptr = 6;
            }
            if ((current_val >> (bit_ptr - 1)) & 1) {
                adj[i][j] = adj[j][i] = 1.0;
            }
            bit_ptr--;
        }
    }
    return n;
}
 
int main(int argc, char *argv[]) {
    if (argc < 2) {
        return 1;
    }
 
    FILE *f = fopen(argv[1], "r");
    if (!f) return 1;
 
    long max_lines = -1;
    if (argc >= 3) {
        max_lines = atol(argv[2]);
        if (max_lines <= 0) {
            fclose(f);
            return 1;
        }
    }
 
    char line[1024];
    double adj[N][N], evals[N];
    int id = 1;
    long lines_read = 0;
 
    clock_t start_time = clock();
 
    while ((max_lines == -1 || lines_read < max_lines) && fscanf(f, "%1023s", line) == 1) {
        lines_read++;
 
        int n = decodeGraph6(line, adj);
        if (n <= 0) continue;
 
        getEigenvalues(adj, n, evals);
 
        int isIntegral = 1;
        for(int i=0; i<n; i++) {
            double rounded = round(evals[i]);
            if(fabs(evals[i] - rounded) > EPS) {
                isIntegral = 0;
                break;
            }
        }
 
        if(isIntegral) {
            printf("%d: %s\n", id++, line);
            fflush(stdout);
        }
    }
 
    clock_t end_time = clock();
    double time_spent = (double)(end_time - start_time) / CLOCKS_PER_SEC;
 
    printf("Czas dzialania dla %ld grafow: %f s\n", lines_read, time_spent);
 
    fclose(f);
    return 0;
}

            getEigenvalues_dev(adj, n, evals);
            isIntegral = 1;
            for(int i=0; i<n; i++) {
                double rounded = round(evals[i]);
                if(fabs(evals[i] - rounded) > EPS) {
                    isIntegral = 0;
                    break;
                }
            }
        }
 
        results[idx] = isIntegral;
    }
}
 
int main(int argc, char *argv[]) {
    if (argc < 2) {
        return 1;
    }
 
    FILE *f = fopen(argv[1], "r");
    if (!f) return 1;
 
    long max_lines = -1;
    if (argc >= 3) {
        max_lines = atol(argv[2]);
        if (max_lines <= 0) {
            fclose(f);
            return 1;
        }
    }
 
    char *h_g6_batch = (char*)malloc(BATCH_SIZE * MAX_G6_LEN * sizeof(char));
    int  *h_results  = (int*)malloc(BATCH_SIZE * sizeof(int));
 
    char *d_g6_batch;
    int  *d_results;
    CUDA_CHECK(cudaMalloc((void**)&d_g6_batch, BATCH_SIZE * MAX_G6_LEN * sizeof(char)));
    CUDA_CHECK(cudaMalloc((void**)&d_results, BATCH_SIZE * sizeof(int)));
 
    char line[1024];
    long lines_read = 0;
    int id = 1;
    int current_batch_size = 0;
 
    clock_t start_time = clock();
    double start_time_sec = (double)start_time / CLOCKS_PER_SEC;
 
    int threadsPerBlock = 256;
 
    while (max_lines == -1 || lines_read < max_lines) {
        if (fscanf(f, "%1023s", line) != 1) break;
 
        lines_read++;
 
        strncpy(&h_g6_batch[current_batch_size * MAX_G6_LEN], line, MAX_G6_LEN - 1);
        h_g6_batch[current_batch_size * MAX_G6_LEN + MAX_G6_LEN - 1] = '\0';
 
        current_batch_size++;
 
        if (current_batch_size == BATCH_SIZE) {
            CUDA_CHECK(cudaMemcpy(d_g6_batch, h_g6_batch, current_batch_size * MAX_G6_LEN * sizeof(char), cudaMemcpyHostToDevice));
 
            int blocksPerGrid = (current_batch_size + threadsPerBlock - 1) / threadsPerBlock;
 
            processGraphsKernel<<<blocksPerGrid, threadsPerBlock>>>(d_g6_batch, d_results, current_batch_size);
            CUDA_CHECK(cudaGetLastError());
 
            CUDA_CHECK(cudaMemcpy(h_results, d_results, current_batch_size * sizeof(int), cudaMemcpyDeviceToHost));
            CUDA_CHECK(cudaDeviceSynchronize());
 
            clock_t current_time = clock();
            double time_found = (double)(current_time - start_time) / CLOCKS_PER_SEC;
 
            for (int i = 0; i < current_batch_size; i++) {
                if (h_results[i]) {
                    printf("%d: %s (czas pobrania paczki: %f s)\n", id, &h_g6_batch[i * MAX_G6_LEN], time_found);
                    fflush(stdout);
                }
                id++;
            }
            current_batch_size = 0;
        }
    }
 
    if (current_batch_size > 0) {
        CUDA_CHECK(cudaMemcpy(d_g6_batch, h_g6_batch, current_batch_size * MAX_G6_LEN * sizeof(char), cudaMemcpyHostToDevice));
 
        int blocksPerGrid = (current_batch_size + threadsPerBlock - 1) / threadsPerBlock;
        processGraphsKernel<<<blocksPerGrid, threadsPerBlock>>>(d_g6_batch, d_results, current_batch_size);
        CUDA_CHECK(cudaMemcpy(h_results, d_results, current_batch_size * sizeof(int), cudaMemcpyDeviceToHost));
        CUDA_CHECK(cudaDeviceSynchronize());
 
        clock_t current_time = clock();
        double time_found = (double)(current_time - start_time) / CLOCKS_PER_SEC;
 
        for (int i = 0; i < current_batch_size; i++) {
            if (h_results[i]) {
                printf("%d: %s (czas pobrania paczki: %f s)\n", id, &h_g6_batch[i * MAX_G6_LEN], time_found);
                fflush(stdout);
            }
            id++;
        }
    }
 
    clock_t end_time = clock();
    double time_spent = (double)(end_time - start_time) / CLOCKS_PER_SEC;
 
    printf("Czas dzialania dla %ld grafow: %f s\n", lines_read, time_spent);
 
    free(h_g6_batch);
    free(h_results);
    cudaFree(d_g6_batch);
    cudaFree(d_results);
    fclose(f);
 
    return 0;
}
