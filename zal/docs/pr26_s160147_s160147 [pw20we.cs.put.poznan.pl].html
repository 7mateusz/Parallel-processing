Modyfikacje względem sito3.c

Plik sito3.c działał jako prosty filtr: czytał grafy z wejścia standardowego, dekodował je funkcją BMKdecode, zamieniał macierz sąsiedztwa na tablicę dla procedury spektralnej przez AToa, a następnie funkcją eigensymmatrix sprawdzał, czy graf jest całkowity i wypisywał go na wyjście. Ten schemat pipeline został zachowany.

1. Zwiększenie zakresu rozmiaru grafów

W sito3.c ustawiono: 

 #define NMAX 20

W nowych wersjach zwiększono rozmiar tablic do: 

 #define MAXN 64

Zmiana pozwala bezpiecznie obsługiwać grafy rzędu 17 oraz zostawia zapas na większe przypadki.

2. Zwiększenie zakresu rozmiaru grafów

W sito3.c procedura eigensymmatrix jednocześnie liczy wartości własne i od razu sprawdza, czy są bliskie liczbom całkowitym. W nowych wersjach rozdzielono to logicznie na kilka etapów: 

 BMKdecode() AToa() eigensymmatrix() isintegral() integral() graph6_integral()

Dzięki temu kod jest czytelniejszy: jedna funkcja dekoduje graf, druga przygotowuje macierz, kolejna liczy wartości własne, a osobna sprawdza ich całkowitość.

3. Dodanie limitu sprawdzanych grafów

Do programów dodano opcjonalny argument limit_grafow. Pozwala on zakończyć pracę po sprawdzeniu określonej liczby grafów, np.: 

 geng -q -c -b -l 17 37:37 | ./sito17_openmp_pipe 8 1000000 > wynik.g6

Dzięki temu można wykonać krótszy test programu albo ograniczyć czas działania.

4. Dodanie statystyk na stderr

W sito3.c wynikowe grafy były wypisywane bezpośrednio na stdout. W nowych wersjach zachowano tę zasadę, ale komunikaty pomocnicze przeniesiono na stderr. Dzięki temu plik wynikowy zawiera tylko grafy w formacie graph6, a nie tekst typu licznik czy podsumowanie.

Algorytm OpenMP

Grafy są wczytywane ze standardowego wejścia do tablicy batch, aż uzbiera się pełna partia o rozmiarze BATCH_SIZE albo skończą się dane.

Przetwarzanie partii odbywa się w funkcji process_batch. Najważniejszy fragment zrównoleglenia wygląda w kodzie tak: 

 #pragma omp parallel for schedule(dynamic, 64) for (i = 0; i < batch_count; i++) keep[i] = (unsigned char)graph6_integral(batch[i]);

Każdy wątek OpenMP dostaje inne indeksy tablicy batch i dla przypisanego grafu wywołuje funkcję graph6_integral. Funkcja ta dekoduje graf przez BMKdecode, a następnie sprawdza całkowitość widma przez integral.

Wyniki nie są wypisywane bezpośrednio wewnątrz pętli równoległej. Każdy wątek zapisuje tylko wynik testu do tablicy keep, a po zakończeniu pętli program sekwencyjnie przechodzi po keep i wypisuje grafy, dla których wartość wynosi 1. 

 for (i = 0; i < batch_count; i++) { if (keep[i]) { fputs(batch[i], stdout); fputc('\n', stdout); (*found)++; } }

Algorytm CUDA

Program czyta grafy ze standardowego wejścia do tablicy batch, a po zebraniu partii przekazuje ją do funkcji process_batch_cuda.

Najpierw cała partia grafów jest kopiowana z pamięci CPU do pamięci GPU: 

 cudaMemcpy(cuda_batch, batch, (size_t)batch_count * BUFSIZE * sizeof(char), cudaMemcpyHostToDevice);

Następnie program oblicza liczbę bloków i uruchamia kernel check_graphs_kernel: 

 blocks = (batch_count + CUDA_THREADS - 1) / CUDA_THREADS; check_graphs_kernel<<<blocks, CUDA_THREADS>>>(cuda_batch, batch_count, cuda_keep);

W kernelu każdy wątek CUDA wyznacza swój numer tid: 

 int tid = blockIdx.x * blockDim.x + threadIdx.x;

Jeżeli tid mieści się w aktualnej liczbie grafów, wątek wybiera odpowiednią linię z tablicy cuda_batch i zapisuje wynik testu do cuda_keep[tid]: 

 const char *line = batch + ((size_t)tid * BUFSIZE); keep[tid] = (unsigned char)d_graph6_integral(line);

Funkcja d_graph6_integral działa po stronie GPU. Dekoduje graf przez d_BMKdecode, a potem sprawdza całkowitość widma przez d_integral.

Po zakończeniu kernela program kopiuje tablicę wyników z GPU do CPU: 

 cudaMemcpy(keep, cuda_keep, (size_t)batch_count * sizeof(unsigned char), cudaMemcpyDeviceToHost);

Na końcu CPU przechodzi po tablicy keep i wypisuje na stdout tylko te grafy z batch, które przeszły test.

Podsumowanie wyników

Porównanie czasów wykonania pokazuje, że zrównoleglenie znacząco skraca czas przetwarzania grafów. Wersja sekwencyjna stanowi punkt odniesienia, natomiast wersje OpenMP i CUDA osiągają wyraźnie lepsze wyniki dla większych zbiorów danych.

Dla 1 000 000 grafów program sekwencyjny wykonał obliczenia w 41,844 s. Wersja OpenMP potrzebowała 10,794 s, a wersja CUDA 9,049 s. Daje to przyspieszenie odpowiednio około 3,9x oraz 4,6x.

Dla 5 000 000 grafów czas wersji sekwencyjnej wyniósł 219,335 s. OpenMP zakończył pracę po 46,37 s, a CUDA po 39,616 s. Przyspieszenie wyniosło więc około 4,7x dla OpenMP i około 5,5x dla CUDA.

Wyniki pokazują, że opłacalność zrównoleglenia rośnie wraz z liczbą analizowanych grafów. Przy większych zestawach danych narzut związany z obsługą równoległości ma mniejsze znaczenie, a większą rolę odgrywa samo rozdzielenie obliczeń między wiele jednostek wykonawczych.

Programy sito5 i sito8 zostały użyte jako dodatkowe punkty odniesienia. Sito5 osiąga bardzo dobre czasy, natomiast sito8 wypada słabo mimo zastosowania CUDA.

Słaby wynik sito8 wynika ze sposobu uruchamiania obliczeń na GPU. Kernel jest wywoływany osobno dla pojedynczego grafu w konfiguracji test«<1,1»>(cuda_bufor);, więc karta graficzna nie wykonuje wielu sprawdzeń równolegle.

Dodatkowo dla każdego grafu wykonywane jest osobne kopiowanie danych oraz synchronizacja. W efekcie znaczną część czasu zajmuje narzut obsługi CUDA, a nie właściwe obliczenia, co tłumaczy słabe wyniki tej wersji.

static int BMKdecode(const char *BUFFOR, int *N, ta A)
{
    int bit, poz, i, j;
    int n;
 
    if (BUFFOR == NULL || BUFFOR[0] == '\0') return 0;
 
    n = ((unsigned char)BUFFOR[0]) - 63;
    if (n < 0 || n > MAXN) return 0;
 
    *N = n;
 
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            A[i][j] = 0;
 
    bit = 32;
    poz = 1;
 
    for (i = 1; i < n; i++)
    {
        for (j = 0; j < i; j++)
        {
            if (bit == 0)
            {
                bit = 32;
                poz++;
            }
 
            if (BUFFOR[poz] == '\0') return 0;
 
            if ((((unsigned char)BUFFOR[poz]) - 63) & bit)
                A[i][j] = A[j][i] = 1;
            else
                A[i][j] = A[j][i] = 0;
 
            bit >>= 1;
        }
    }
 
    return 1;
}

{

    a[0] = 0.0L;
    poz = 1;
 
    for (i = 0; i < N; i++)
    {
        A[i][i] = 0;
        for (j = 0; j <= i; j++)
            a[poz++] = A[i][j] ? 1.0L : 0.0L;
    }
}

            s += g * g;

            a[j] = 0.0L;

            e2[L] = s;
            g = sqrtl(s);
            if (h >= 0.0L) g = -g;
            e[L] = g;
            s = 1.0L / (s - h * g);
            a[j] = h - g;
            h = 0.0L;
            L1 = L - 1;
            k3 = 1;
 
            for (j = 1; j <= L1; j++)
            {
                k4 = k3;
                g = 0.0L;
 
                for (k = 1; k <= L1; k++)
                {
                    g += a[k4] * a[i + k];
                    if (k < j) z = 1;
                    else z = k;
                    k4 += z;
                }
 
                k3 += j;
                g *= s;
                e[j] = g;
                h += a[i + j] * g;
            }
 
            h *= 0.5L * s;
            k3 = 1;
 
            for (j = 1; j <= L1; j++)
            {
                s = a[i + j];
                g = e[j] - h * s;
                e[j] = g;
 
                for (k = 1; k <= j; k++)
                {
                    a[k3] += -s * e[k] - a[i + k] * g;
                    k3++;
                }
            }
        }
 
        h = d[L];
        d[L] = a[i + L];
        a[i + L] = h;
    }
 
    h = d[1];
    d[1] = a[1];
    a[1] = h;
    e[1] = 0.0L;
    e2[1] = 0.0L;
 
    s = d[n];
    t = fabsl(e[n]);
    mn = s - t;
    ma = s + t;
 
    for (i = n - 1; i >= 1; i--)
    {
        u = fabsl(e[i]);
        h = t + u;
        t = u;
        s = d[i];
 
        u = s - h;
        if (u < mn) mn = u;
 
        u = s + h;
        if (u > ma) ma = u;
    }

        x[i] = ma;
    }

    s = fabsl(ma);

        s = mn;
        i = k;

            cond = 0;
            g = Lb[i];
            if (s < g)
                s = g;
            else
            {
                i--;
                if (i >= k1) cond = 1;
            }

                }

}

            bit >>= 1;
        }
    }
 
    return 1;
}
 
static void AToa(int N, ta A, long double *a)
{
    int poz, i, j;

    poz = 1;

        A[i][i] = 0;
        for (j = 0; j <= i; j++)
            a[poz++] = A[i][j] ? 1.0L : 0.0L;
    }
}
 
static int eigensymmatrix(int n, long double *a, int k1, int k2, long double *x)
{
    int i, j, k, k3, k4, L, L1, z;
    long double lambda, eps, g, h, ma, mn, norm, s, t, u, w;
    int cond;
    long double d[MAXN + 1], e[MAXN + 1], e2[MAXN + 1], Lb[MAXN + 1];
 
    if (!((1 <= k1) && (k1 <= k2) && (k2 <= n) && (n <= MAXN)))
        return 0;
 
    i = 0;
    for (L = 1; L <= n; L++)
    {
        i += L;
        d[L] = a[i];
    }
 
    for (L = n; L >= 2; L--)
    {
        i--;
        j = i;
        h = a[j];
        s = 0.0L;
 
        for (k = L - 2; k >= 1; k--)
        {
            i--;
            g = a[i];
            s += g * g;
        }
 
        i--;
 
        if (s == 0.0L)
        {
            e[L] = h;
            e2[L] = h * h;
            a[j] = 0.0L;
        }
        else
        {
            s += h * h;
            e2[L] = s;
            g = sqrtl(s);
            if (h >= 0.0L) g = -g;
            e[L] = g;
            s = 1.0L / (s - h * g);
            a[j] = h - g;
            h = 0.0L;
            L1 = L - 1;
            k3 = 1;
 
            for (j = 1; j <= L1; j++)
            {
                k4 = k3;
                g = 0.0L;
 
                for (k = 1; k <= L1; k++)
                {
                    g += a[k4] * a[i + k];
                    if (k < j) z = 1;
                    else z = k;
                    k4 += z;
                }
 
                k3 += j;
                g *= s;
                e[j] = g;
                h += a[i + j] * g;
            }
 
            h *= 0.5L * s;
            k3 = 1;
 
            for (j = 1; j <= L1; j++)
            {
                s = a[i + j];
                g = e[j] - h * s;
                e[j] = g;
 
                for (k = 1; k <= j; k++)
                {
                    a[k3] += -s * e[k] - a[i + k] * g;
                    k3++;
                }
            }
        }
 
        h = d[L];
        d[L] = a[i + L];
        a[i + L] = h;
    }
 
    h = d[1];
    d[1] = a[1];
    a[1] = h;
    e[1] = 0.0L;
    e2[1] = 0.0L;
 
    s = d[n];
    t = fabsl(e[n]);
    mn = s - t;
    ma = s + t;
 
    for (i = n - 1; i >= 1; i--)
    {
        u = fabsl(e[i]);
        h = t + u;
        t = u;
        s = d[i];
 
        u = s - h;
        if (u < mn) mn = u;
 
        u = s + h;
        if (u > ma) ma = u;
    }
 
    for (i = 1; i <= n; i++)
    {
        Lb[i] = mn;
        x[i] = ma;
    }
 
    norm = fabsl(mn);
    s = fabsl(ma);
    if (s > norm) norm = s;
 
    w = ma;
    lambda = norm;
    (void)lambda;
 
    for (k = k2; k >= k1; k--)
    {
        eps = 7.28e-17L * norm;
        s = mn;
        i = k;
 
        do
        {
            cond = 0;
            g = Lb[i];
            if (s < g)
                s = g;
            else
            {
                i--;
                if (i >= k1) cond = 1;
            }
        }
        while (cond);
 
        g = x[k];
        if (w > g) w = g;
 
        while (w - s > 2.91e-16L * (fabsl(s) + fabsl(w)) + eps)
        {
            L1 = 0;
            g = 1.0L;
            t = 0.5L * (s + w);
 
            for (i = 1; i <= n; i++)
            {
                if (g != 0.0L)
                    g = e2[i] / g;
                else
                    g = fabsl(6.87e15L * e[i]);
 
                g = d[i] - t - g;
                if (g < 0.0L) L1++;
            }
 
            if (L1 < k1)
            {
                s = t;
                Lb[k1] = s;
            }
            else
            {
                if (L1 < k)
                {
                    s = t;
                    Lb[L1 + 1] = s;
                    if (x[L1] > t) x[L1] = t;
                }
                else
                {
                    w = t;
                }
            }
        }
 
        u = 0.5L * (s + w);
        x[k] = u;
    }
 
    return 1;
}
 
static int isintegral(int N, long double *x)
{
    int i;
 
    for (i = 1; i <= N; i++)
    {
        long double u = x[i];
        long double nearest = roundl(u);
 
        if (fabsl(u - nearest) > EPS_INT)
            return 0;
    }
 
    return 1;
}
 
static int integral(int N, ta A)
{
    long double a[MAXPACKED];
    long double x[MAXN + 1];
 
    if (N <= 0 || N > MAXN) return 0;
 
    AToa(N, A, a);
 
    if (!eigensymmatrix(N, a, 1, N, x))
        return 0;
 
    return isintegral(N, x);
}

{

}

int main(int argc, char *argv[])
{
    char (*batch)[BUFSIZE];
    unsigned char *keep;
    char buffer[BUFSIZE];
    int batch_count = 0;
    int threads = 0;
    long long threads_value = 0;
    long long read_count = 0;
    long long checked = 0;
    long long found = 0;
    long long limit_graphs = 0;
 
    if (argc >= 2)
    {
        if (strcmp(argv[1], "-h") == 0 || strcmp(argv[1], "--help") == 0)
        {
            usage(argv[0]);
            return EXIT_SUCCESS;
        }
 
        if (!parse_nonnegative_ll(argv[1], &threads_value) || threads_value > 2147483647LL)
        {
            fprintf(stderr, "Niepoprawna liczba watkow.\n");
            usage(argv[0]);
            return EXIT_FAILURE;
        }
 
        threads = (int)threads_value;
        if (threads > 0)
            omp_set_num_threads(threads);
    }
 
    if (argc >= 3)
    {
        if (!parse_nonnegative_ll(argv[2], &limit_graphs))
        {
            fprintf(stderr, "Niepoprawny limit grafow.\n");
            usage(argv[0]);
            return EXIT_FAILURE;
        }
    }
 
    if (argc > 3)
    {
        fprintf(stderr, "Za duzo parametrow.\n");
        usage(argv[0]);
        return EXIT_FAILURE;
    }
 
    batch = (char (*)[BUFSIZE])malloc((size_t)BATCH_SIZE * sizeof(*batch));
    keep = (unsigned char *)malloc((size_t)BATCH_SIZE * sizeof(*keep));
 
    if (batch == NULL || keep == NULL)
    {
        fprintf(stderr, "Blad alokacji pamieci.\n");
        free(batch);
        free(keep);
        return EXIT_FAILURE;
    }
 
    while (fgets(buffer, sizeof(buffer), stdin) != NULL)
    {
        if (limit_graphs > 0 && read_count >= limit_graphs)
            break;
 
        chomp(buffer);
        snprintf(batch[batch_count], BUFSIZE, "%s", buffer);
        batch_count++;
        read_count++;
 
        if (batch_count == BATCH_SIZE)
        {
            process_batch(batch, batch_count, keep, &found);
            checked += batch_count;
            batch_count = 0;
 
            if ((checked % PROGRESS_EVERY) == 0)
            {
                fprintf(stderr, "sprawdzono: %lld, znaleziono: %lld\n", checked, found);
                fflush(stderr);
            }
        }
    }
 
    if (batch_count > 0)
    {
        process_batch(batch, batch_count, keep, &found);
        checked += batch_count;
    }
 
    fflush(stdout);
    fprintf(stderr, "Koniec. sprawdzono: %lld, znaleziono: %lld\n", checked, found);
 
    free(batch);
    free(keep);
    return EXIT_SUCCESS;
}

__device__ int d_BMKdecode(const char *BUFFOR, int *N, unsigned char *A)
{
    int bit, poz, i, j;
    int n;
 
    if (BUFFOR == NULL || BUFFOR[0] == '\0') return 0;
 
    n = ((unsigned char)BUFFOR[0]) - 63;
    if (n < 0 || n > MAXN) return 0;
 
    *N = n;
 
    for (i = 0; i < n; i++)
        for (j = 0; j < n; j++)
            A[AIDX(i, j)] = 0;
 
    bit = 32;
    poz = 1;
 
    for (i = 1; i < n; i++)
    {
        for (j = 0; j < i; j++)
        {
            if (bit == 0)
            {
                bit = 32;
                poz++;
            }
 
            if (BUFFOR[poz] == '\0') return 0;
 
            if ((((unsigned char)BUFFOR[poz]) - 63) & bit)
            {
                A[AIDX(i, j)] = 1;
                A[AIDX(j, i)] = 1;
            }
            else
            {
                A[AIDX(i, j)] = 0;
                A[AIDX(j, i)] = 0;
            }
 
            bit >>= 1;
        }
    }
 
    return 1;
}

        if (limit_graphs > 0 && read_count >= limit_graphs)
            break;
 
        chomp(buffer);
        snprintf(batch[batch_count], BUFSIZE, "%s", buffer);
        batch_count++;
        read_count++;
 
        if (batch_count == BATCH_SIZE)
        {
            process_batch_cuda(batch, batch_count, keep,
                               cuda_batch, cuda_keep, &found);
            checked += batch_count;
            batch_count = 0;
 
            if ((checked % PROGRESS_EVERY) == 0)
            {
                fprintf(stderr, "sprawdzono: %lld, znaleziono: %lld\n", checked, found);
                fflush(stderr);
            }
        }
    }
 
    if (batch_count > 0)
    {
        process_batch_cuda(batch, batch_count, keep,
                           cuda_batch, cuda_keep, &found);
        checked += batch_count;
    }
 
    fflush(stdout);
    fprintf(stderr, "Koniec. sprawdzono: %lld, znaleziono: %lld\n", checked, found);
 
    HANDLE_CUDA(cudaFree(cuda_batch));
    HANDLE_CUDA(cudaFree(cuda_keep));
    HANDLE_CUDA(cudaDeviceReset());
 
    free(batch);
    free(keep);
    return EXIT_SUCCESS;
}
