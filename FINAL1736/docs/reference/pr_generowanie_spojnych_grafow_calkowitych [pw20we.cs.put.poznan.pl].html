widma.mzn
int: n ;
int: k ; 
array[1..n] of var -(n-1)..(n-1): x;
 
constraint sum(x)=0;
constraint x[1]>x[2];
constraint forall(i in 2..(n-1)) (x[i]>=x[i+1]);
constraint forall(i in 2..n) (x[1]>=abs(x[i]));
constraint sum([i*i | i in x])=2*k;
 
solve satisfy; 
 
n=15;
k=68;

Rozwiązania suboptymalne (grafy prawie całkowite)

Funkcja celu (minimalizacja)

  • ∑ni=1|min(λi−⌈λi⌉,λi−⌊λi⌋)|∑i=1n|min(λi−⌈λi⌉,λi−⌊λi⌋)|
def funkcjacelu0(Sp):
  return sum([abs(round(e)-e) for e in Sp])

Funkcja celu (maksymalizacja)

  • n−2⋅∑ni=1|min(λi−⌈λi⌉,λi−⌊λi⌋)|n−2⋅∑i=1n|min(λi−⌈λi⌉,λi−⌊λi⌋)|
def funkcjacelu1(Sp):
  return len(Sp) - 2*sum([abs(round(e)-e) for e in Sp])

Liczba wartości całkowitych w spektrum

import math
def liczbacalkowitych(Sp):
return sum([1 for v in Sp if math.isclose(v,round(v),abs_tol=0.001)])
